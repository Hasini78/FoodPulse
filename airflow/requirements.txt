# Packages imported by the tasks foodpulse_pipeline runs inside the Airflow image.

# Included because the default task commands import them:
# pandas, numpy, pyarrow: ETL, mining, forecast, and the Snowflake dry-run plan

# nltk, spacy: lemmatizers are optional and the sentiment code falls back when they are absent
# snowflake-connector-python: dry-run never connects; connect() imports the connector only for --execute
# FastAPI, database, plotting-dashboard, and dev tools: the DAG does not import them
